# Numero Secreto
Número Secreto é um simples jogo feito em Java para praticar a Estrutura de Repetição While.
Quando o usuário iniciar o jogo, será gerado um número aleatório e que precisará ser adivinhado. Toda vez que o jogador digitar um número, será dado um feedback se o número que ele digitou está muito alto ou muito baixo em relação ao número sorteado e ele tentará até acertar o número correto. 
Quando o jogador acertar o número o programa será encerrado, dando uma mensagem de parabéns ao jogador e revelando qual era o número.
